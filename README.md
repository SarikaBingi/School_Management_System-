# School Management System – Java

A simple **School Management System** developed using Java to manage students, teachers, fees, and salaries.

## 📌 Description

This project is a basic school management application that keeps track of the school's financial activities. It records the fees paid by students, the salaries paid to teachers, and calculates the total money earned and spent by the school.

## ✨ Features

- Manage student information
- Manage teacher information
- Track student fees
- Record teacher salaries
- Calculate total money earned by the school
- Calculate total money spent on teacher salaries
- Display student fee payment details

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
